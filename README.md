# Cookbook

Cookbook is a simple Android application for managing recipes and ingredients. The app allows users to browse recipe collections, search and filter recipes by category or favourites, view preparation steps, and manage ingredient usage in a clean and easy-to-use interface.

This project is a semester project for the Basic Android Development course.

## Features
- Browse and search recipes
- Save favourites and filter the list
- View ingredients and cooking steps for each recipe
- Manage ingredients and recipe details in the app
- Built with Kotlin and Jetpack Compose
